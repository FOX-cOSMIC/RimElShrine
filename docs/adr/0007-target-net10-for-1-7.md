# Build the 1.7 version for net10.0, and keep the 1.6 version on net472

Krafs.Rimworld.Ref 1.7.4995-unstable supports only net10.0. The installed RimWorld 1.7 runs as a .NET app (its folder holds RimWorld.runtimeconfig.json), so a 1.7 mod must target net10.0 as well. The 1.6 build stays on net472.
