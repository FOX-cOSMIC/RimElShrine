# Target the installed RimWorld build

The brief named 1.7.4990 rev1069. The unstable build installed on this PC was 1.7.4998 rev1299 when this decision was made, and the latest Z-Levels harness run loaded it. The port targets the installed build.

Updated 2026-11-07: Lucas chose the installed build for decision D2. The installed build is now 1.7.5000 rev1275, from the Steam unstable branch, and the validation runs from 2026-11-07 use it. The port still compiles against Krafs.Rimworld.Ref 1.7.4995-unstable. ADR 0006 explains that reference, and it is one step behind the installed game.
