# One build property selects the RimWorld version

RimWorldVersion selects the version for the three projects. Its default is 1.6, so the 1.6 paths and references stay as they are. The 1.7 build writes only to RimElShrine.Shields/1.7/ and references Krafs.Rimworld.Ref 1.7.4995-unstable, the newest version on NuGet.
